# Отчёт на 28.04

## Описание проекта
### Тема проекта:
Разделение потоков данных на уровне драйвера ресурсов
### Описание:
Шаблон предназначен для разделения потоков данных для ограничения доступа к ресурсам на уровне драйвера ресурсов с целью обеспечения конфиденциальности, целостности и взаимного невлияния потоков данных. Примером применения шаблона является уменьшение поверхности атаки на ВФС, за счет разделения одной ВФС на несколько: например, отдельно для работы с внешней сетью и отдельно для работы с внутренней сетью и блочным устройством
## Отчёт
### Особенности шаблона:
Реализация разделения потоков позволит изолировать критические данные друг от друга. Например, команды изменения скорости и направления должны обрабатываться отдельно от данных маршрута, а логирование вообще не должно иметь доступа к управляющим командам.
### Технические особенности:
Можно реализовать через:
1. Разделение очередей сообщений на три независимых канала (управление, навигация, логи)
2. Внедрение проверки прав доступа перед обработкой сообщений.
